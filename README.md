# divine-whisper-merge-helper
Divine Whisper merge helper: one-command script to safely merge four key branches (repo-ecos, post-launch, spec-v7, ray-poc) into main. Aborts on conflict, fetches first, uses no-ff merges. For maintaining the inward-physics ecosystem repo. Co-authored by Daniel Jacob Read IV &amp; Shane Travis Horman (ĀRU Intelligence). MIT-licensed.
